# Release Notes Video

Skill that generates short animated showcase videos from software release note descriptions using HyperFrames.

Agents write HTML/CSS compositions that mock the relevant UI (terminal, Slack, GitHub CI, etc.) from the description, then render a local MP4.

See [SKILL.md](./SKILL.md) for the full workflow and the `examples/` directory for ready-to-render compositions based on fake release notes.
